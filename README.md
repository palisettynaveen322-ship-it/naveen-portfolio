# P. Naveen — React Portfolio

A responsive, premium-dark portfolio with subtle futuristic styling. Built with React + Vite.

## Run locally

1. Install Node.js (LTS).
2. Extract this ZIP.
3. Open the extracted `naveen-portfolio` folder in VS Code.
4. Open a terminal in that folder and run:

```bash
npm install
npm run dev
```

5. Open the local URL printed by Vite (usually `http://localhost:5173`).

## Before publishing — personalize these details

Open `src/main.jsx` and update the `profile` object near the top:

- `email`
- `github`
- `linkedin`

Also review the project descriptions and links. Add a real project repository link for TabAlert and YOLO Person Counter if they are published. Replace or remove any item that is not ready to show recruiters.

## Add your resume

Place your PDF in the `public` folder (for example, `public/Naveen-Resume.pdf`) and add a Resume button in the hero section if you want to offer it.

## Profile photo

Your supplied portrait is included at `public/images/naveen-profile.jpg`.

## Build for production

```bash
npm run build
```

The production site is generated in the `dist` folder.

## Deploy

You can deploy the project to Vercel by importing the extracted project folder/repository and using the default Vite build settings.
